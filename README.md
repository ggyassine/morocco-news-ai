# Morocco News AI

مساعد أخبار مغربية موجه للعمل الصحفي. يجمع الأخبار ذات الصلة بالمغرب، ويركز على انتقالات اللاعبين المغاربة المحترفين في الخارج.

## ما الذي يفعله؟

- يفحص المصادر كل 15 دقيقة.
- يرشح الأخبار المرتبطة بالمغرب واللاعبين المغاربة.
- يمنع تكرار الرابط.
- يصنف الخبر.
- يحدد حالة خبر الانتقال دون رفع درجة اليقين فوق المصدر.
- يحفظ الأخبار في SQLite.
- يرسل الأخبار الجديدة عبر Resend إلى `yassinehamini9@gmail.com` بعد إعداد مفاتيح البريد.
- يوفر Dashboard محليا على `http://localhost:8080`.
- يوفر `/health` و`/api/news`.

## مستويات المصادر

A = مصدر أولي أو رسمي.
B = مؤسسة إعلامية موثوقة.
C = مصدر متخصص.
D = مصدر غير مؤكد.

وجود خبر في مصدر B لا يحوله تلقائيا إلى خبر رسمي. الإعلان الرسمي من النادي أو المؤسسة يظل المرجع الأعلى في حالة الانتقالات.

## التشغيل المحلي

1. أنشئ ملف `.env` من `.env.example`.
2. ضع `OPENAI_API_KEY` إذا أردت التصنيف والتلخيص بالذكاء الاصطناعي.
3. أنشئ حساب Resend واضبط `RESEND_API_KEY` و`FROM_EMAIL`.
4. نفذ:

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python main.py
```

في Windows:

```powershell
python -m venv .venv
.venv\\Scripts\\activate
pip install -r requirements.txt
python main.py
```

## Docker

```bash
docker compose up -d --build
```

المشروع جاهز للتشغيل، لكن لا توجد داخل هذا الملف مفاتيح OpenAI أو Resend. يجب وضعها في `.env`. كذلك يجب التحقق من أن RSS لكل ناشر ما زال فعالا في بيئة الاستضافة، لأن الناشرين يغيرون عناوين الخلاصات أحيانا.
